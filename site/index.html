awake

Keep your machine awake and your status Available.

Most "prevent sleep" tools only keep the machine running. Chat apps decide whether you are Away from the system's input idle time, which keeps counting. awake handles both:

  • Inhibits system sleep, and optionally display sleep, so VPNs, agents and connections stay up.
  • Resets the idle timer and re-reads it afterwards to verify the reset worked. If a method doesn't work, awake tries the next one.
  • macOS, Windows and Linux, as a menu bar / tray app or a CLI that can run as a login service.
  • Open source under the MIT License. No account, no telemetry.

Install

Tray app

macOS .dmg Windows .exe Linux .deb

macOS 11+ (Apple silicon and Intel) · Windows 10/11 x64 · Linux x86_64. Also available: .msi, .AppImage, all files and checksums.

Or with Homebrew:

brew install --cask nolliebigspin/tap/awake-tray

CLI

brew install nolliebigspin/tap/awake

Or with the install script (macOS / Linux):

curl --proto '=https' --tlsv1.2 -LsSf https://github.com/nolliebigspin/awake/releases/latest/download/awake-cli-installer.sh | sh

Windows (PowerShell):

powershell -ExecutionPolicy Bypass -c "irm https://github.com/nolliebigspin/awake/releases/latest/download/awake-cli-installer.ps1 | iex"

Prebuilt binaries and building from source: see the README.

macOS

To reset the idle timer, awake posts synthetic input, which requires Accessibility access. The tray app has a menu item that opens the right settings pane.

Use responsibly

awake simulates keyboard and mouse input (an F15 key press or a 1 px mouse move). Security software on managed devices may flag or block this, and it may be against your employer's IT or presence policy. Check with your IT department before using it on a work machine. You are responsible for how you use it.
